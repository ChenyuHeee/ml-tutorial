# 阶段 4：深度学习与 PyTorch（4–6 周）

目标：能自己搭建、训练、调试一个中小型深度学习模型，并写出可复现的训练与推理代码。

## 训练与调试核心
- 反向传播直觉、损失函数与梯度
- 初始化、激活函数
- 正则化：Dropout、Weight Decay
- 归一化：BatchNorm（理解训练/推理差异）
- 优化器：SGD/Adam；学习率与 scheduler
- 过拟合/欠拟合诊断：看训练曲线 + 错误样本

## 建议选择一个方向深入（选 1 个）
### A. 计算机视觉（CV）
- CNN 基础
- 迁移学习：加载预训练模型（如 ResNet），替换分类头
- 数据增强：翻转、裁剪、颜色抖动（控制强度）

### B. 自然语言处理（NLP）
- 从 TF-IDF 过渡到 Transformer 基本概念
- 微调预训练模型（HuggingFace）：数据处理、训练、评估

### C. 表格数据深度学习（Tabular DL）
- MLP + 类别特征 embedding
- 与 GBDT 对比优劣（不要迷信 DL）

## 阶段项目（选 1 个做深）
- 图像分类（如 CIFAR-10 或自建小数据集）
- 文本分类（情感/意图识别，微调 BERT/RoBERTa 等）

## 交付物要求
- `train.py`：训练、保存权重、记录指标
- `predict.py`：加载权重推理
- `README.md`：数据、指标、训练配置与复现方式
