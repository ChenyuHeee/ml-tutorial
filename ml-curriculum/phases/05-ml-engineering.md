# 阶段 5：ML 工程化与实践闭环（2–4 周）

目标：从“会训练”走向“能落地”，具备可复现、可部署、可迭代的基本工程能力。

## 实验与复现
- 目录结构清晰：数据/特征/模型/日志分离
- 配置化：用参数或 YAML 管理超参与路径
- 随机性控制：固定随机种子、记录依赖版本

## 推理与服务化（最小闭环）
- 模型保存/加载：权重 + 预处理器（scaler/encoder）
- 推理脚本：批量推理、输出结果文件
- 在线服务（可选）：FastAPI 提供 `POST /predict`

## 监控与漂移（了解概念即可）
- 数据分布变化（输入漂移）
- 线上指标退化与告警

## 最终大作业（强烈建议）
- 选一个真实问题做端到端系统：
  数据 → 训练 → 评估 → 推理 API → Demo

## 自检
- 新环境一键复现：能否从 0 训练并得到相近指标？
- 推理输入边界：空值、异常值、类别未见过时是否可控？
