# 机器学习课程体系（面向计算机专业：能上手实践）

这是一套以“能独立完成机器学习项目”为目标的学习路径。默认你已具备基础编程能力（建议 Python）。

## 你学完应达到的能力
- 能把问题抽象成监督/无监督/深度学习任务，并选择合适的指标与验证方式
- 能用 scikit-learn 完成：数据清洗 → 特征工程 → 训练 → 调参 → 评估 → 复现
- 能用 PyTorch 完成中小型深度学习模型训练、调试与推理脚本

## 推荐学习顺序
1. 阶段 0：工具与基础（1 周） → [phases/00-setup.md](phases/00-setup.md)
2. 阶段 1：数学与概率（2–4 周，并行补齐） → [phases/01-math.md](phases/01-math.md)
3. 阶段 2：经典机器学习核心（4–6 周） → [phases/02-classic-ml.md](phases/02-classic-ml.md)
4. 阶段 3：无监督与表示学习（2–3 周） → [phases/03-unsupervised.md](phases/03-unsupervised.md)
5. 阶段 4：深度学习与 PyTorch（4–6 周） → [phases/04-deep-learning.md](phases/04-deep-learning.md)
6. 阶段 5：ML 工程化与闭环（2–4 周） → [phases/05-ml-engineering.md](phases/05-ml-engineering.md)

## 项目与打卡

- 每周：按 12 周路线推进 + 用周打卡模板复盘
- 每个阶段：至少做 1 个小项目/练习，保持“可复现”

> 备注：你可以把项目仓库直接建在同一工作区，例如 `ml-curriculum-work/`，保持和本课程文档分离。
