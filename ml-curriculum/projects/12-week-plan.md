# 12 周路线（每周 8–12 小时）

这是“最小可行”的 12 周节奏：快速建立闭环，确保能做出作品。

## 第 1–2 周：工具 + 经典 ML 基本流程
- 环境与数据分析（阶段 0）
- 监督学习任务：训练/验证/测试、指标、简单模型
- 交付：一个可复现的数据分析小报告

## 第 3–6 周：经典 ML 核心（阶段 2）
- 特征工程与泄漏规避
- 树模型与交叉验证
- 误差分析与调参
- 交付：Tabular 项目（端到端）

## 第 7 周：无监督（阶段 3）
- 聚类 + 降维可视化
- 交付：分群画像小项目（分析报告）

## 第 8–11 周：深度学习（阶段 4）
- PyTorch 训练流程与调试
- 选方向做一个项目（CV 或 NLP 或 Tabular DL）
- 交付：深度学习项目（训练/推理脚本齐全）

## 第 12 周：工程化闭环（阶段 5）
- 整理项目结构与 README
- 补齐推理脚本/（可选）FastAPI
- 交付：作品集级仓库（可复现 + 可演示）

> 建议：数学（阶段 1）贯穿全程，每周固定 2–3 小时补齐即可。
